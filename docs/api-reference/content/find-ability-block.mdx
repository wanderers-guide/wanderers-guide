openapi: "POST /find-ability-block"
---

For large catalogs, pass `page_size` (1–1,000). Results are ordered by ID; send the
last returned ID as `after_id` on the next request, preserving the same filters.
Continue until a page has fewer rows than `page_size`; an exactly full final page
requires one empty read. `after_id` requires `page_size`. Omitting pagination keeps
the existing complete-array or scalar-ID response.
